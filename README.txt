NØX.DEV Portfolio — first version

WHAT'S INCLUDED
- index.html: complete responsive portfolio (HTML, CSS, and JavaScript in one file)
- No installation or paid tools needed to preview it.

HOW TO OPEN
1. Extract this ZIP.
2. Open the folder and double-click index.html.
3. It should open in your browser.

HOW TO EDIT
- Open index.html in VS Code or another text editor.
- Search for the text you want to change and replace it.
- Save the file, then refresh your browser.

BEFORE PUBLISHING
- Replace your-email@example.com with an email you are comfortable sharing publicly.
- Replace the GitHub homepage link with your own profile URL.
- Make sure the project descriptions accurately reflect your work.
- Do not publish your home address, private phone number, school timetable, or other sensitive personal details.

NEXT LEARNING STEPS
1. Read the HTML structure in index.html.
2. Find the CSS variables under :root to change the colours.
3. Find the JavaScript at the bottom for the mobile menu and scroll animations.
4. When you're ready, push the folder to a GitHub repository and deploy it as a Render Static Site.
